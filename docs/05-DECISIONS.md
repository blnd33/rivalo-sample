# Decisions register

Each item is **OPEN** until the owner (and legal or compliance review where noted) confirms it. Code stores open rules as **configurable drafts** that **cannot be activated** until confirmed. Nothing below is guessed into live scoring, prize or payment behavior.

## How to close a decision
1. Record the answer and the date here.
2. Change the matching configuration in the admin panel (not in code, where possible).
3. If code must change, reference the decision ID (for example, `D2`) in the commit message.
